## 2. Análisis de la Base Teórica y Documentación (`docs/`)

1. **Social Force Model sin Fuerza Social ([Teorica_6.pdf](file:///home/lolo/Documents/facultad/sds/Simulacion-De-Sistemas/TP5/docs/Teorica_6.pdf) pp. 28–33)**:
   - Ecuación: $m\ddot{\mathbf{r}}_i = \mathbf{F}_{D,i} + \mathbf{F}_{G,i}$, omitiendo $\mathbf{F}_{S,i}$.
   - Fuerza de deseo: $\mathbf{F}_{D,i} = m\frac{v_{d,i}\hat{\mathbf{e}}_t - \mathbf{v}_i}{\tau}$ con $\tau = 0.5\text{ s}$, $m = 80\text{ kg}$ y radio $r = 0.25\text{ m}$ (fijado por el enunciado).
   - Fuerza granular de contacto ($\varepsilon_{ij} = d_{ij} - 2r < 0$): $\mathbf{F}_{G,ij} = (-\varepsilon_{ij}k_n)\hat{\mathbf{n}}_{ij} + (v^t_{ij}\varepsilon_{ij}k_t)\hat{\mathbf{t}}_{ij}$ con $k_n = 1.2\times 10^5\text{ N/m}$ y $k_t = 2.4\times 10^5\text{ kg/(m}\cdot\text{s)}$.
2. **Contractile Particle Model ([Teorica_6.pdf](file:///home/lolo/Documents/facultad/sds/Simulacion-De-Sistemas/TP5/docs/Teorica_6.pdf) pp. 56–61; Baglietto & Parisi 2011)**:
   - Radio variable $r_i \in [r_{\min}, r_{\max}] = [0.10, 0.25]\text{ m}$, rapidez $v_d(r_i) = v_{\max}\left(\frac{r_i - r_{\min}}{r_{\max} - r_{\min}}\right)^\beta$ con $\beta = 0.9$, relajación $\Delta r = \frac{r_{\max}}{\tau}\Delta t$ con $\tau = 0.5\text{ s}$, velocidad de escape en contacto ($r_i = r_{\min}$) $v_e = v_d$ y paso fijo $\Delta t = \frac{r_{\min}}{2v_{\max}}$.
3. **Heurísticas de Elusión ([Teorica_7.pdf](file:///home/lolo/Documents/facultad/sds/Simulacion-De-Sistemas/TP5/docs/Teorica_7.pdf) pp. 8–18 y 27–30)**:
   - **Diapo 9 (Predictive Collision Avoidance)**: predice el tiempo de máximo acercamiento $t_{ca}$ y distancia $d_{ca}$ extrapolando linealmente las trayectorias; define colisión futura cuando $0 < t_{ca} \le t_{\text{horizonte}}$ y $d_{ca} < \rho$.
   - **Diapo 16 (Target Temporal)**: ante colisión predicha, desplaza lateralmente el target para inducir el desvío y vuelve al target final cuando cesa el conflicto (base directa de las **Capas A y B**).
   - **Diapos 28–29 (CPM con mecanismo de elusión, Laje & Parisi 2020)**: suma un vector repulsivo en el cono de visión delantero $\mathbf{n}_c^i = \mathbf{e}_{ij} A_p e^{-d_{ij}/B_p}\cos\theta_j$ para obtener $\mathbf{e}_a^i = \frac{\mathbf{n}_c^i + \mathbf{e}_t^i}{\|\mathbf{n}_c^i + \mathbf{e}_t^i\|}$ cuando no hay contacto (base de la **Capa F**).

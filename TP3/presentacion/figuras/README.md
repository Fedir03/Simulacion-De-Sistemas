# Figuras de la presentacion

Guardar aqui figuras optimizadas para la exposicion. Reutilizar las del informe
cuando comuniquen bien a distancia; crear una variante solo cuando necesite
menos detalle, tipografia mas grande o una relacion de aspecto diferente.

Usar nombres descriptivos y conservar trazabilidad hacia los datos y el script
que produjo cada imagen. Verificar contraste, tamanos de ejes y leyendas en una
pantalla completa, no solamente en el editor.

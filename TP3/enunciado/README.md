# Enunciado

Guardar aqui la consigna original, anexos oficiales y aclaraciones de la
catedra. Usar nombres estables, por ejemplo `TP3_Enunciado.pdf`, y no modificar
el archivo original: cualquier interpretacion o decision debe documentarse en
el README general o en un documento separado claramente identificado.

Antes de implementar, extraer requisitos verificables: entradas, salidas,
parametros obligatorios, casos limite, graficos solicitados y formato de
entrega. Cuando haya una aclaracion posterior, registrar tambien su fecha y
procedencia.

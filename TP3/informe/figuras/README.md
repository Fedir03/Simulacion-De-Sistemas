# Figuras del informe

Guardar solo las figuras finales citadas por el informe, preferentemente en
PDF para graficos vectoriales y PNG para imagenes rasterizadas. Usar nombres
descriptivos en minusculas, sin espacios, y no acumular variantes como
`final`, `final2` o `nuevo`.

Cada archivo debe poder regenerarse con un script y parametros documentados.
Si informe y presentacion usan exactamente la misma figura, elegir una fuente
canonica y automatizar la copia para evitar divergencias.

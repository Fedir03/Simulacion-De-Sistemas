# Codigo fuente y pruebas

Esta carpeta sigue la disposicion estandar de Maven. `main/` contiene codigo de
produccion y `test/` contiene pruebas. Mantener ambas jerarquias en paralelo
para que cada componente importante tenga una prueba facil de localizar.

No guardar aqui resultados de corridas, figuras, notebooks ni clases
compiladas. La salida de Maven pertenece a `target/` y esta ignorada por Git.

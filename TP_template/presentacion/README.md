# Presentacion

Esta carpeta contiene una presentacion Beamer reutilizable y sus recursos.
Partir de `presentacion_template.tex`, completar sus metadatos y ajustar las
secciones al relato del nuevo trabajo. El logo institucional se comparte con
el informe.

La presentacion debe sintetizar el informe, no copiarlo. Priorizar una idea por
diapositiva, texto breve, tipografia legible y figuras visibles a distancia.
Toda conclusion debe estar respaldada por una figura, tabla o medicion ya
explicada. Ensayar con el PDF final y comprobar enlaces, animaciones y tiempo.

## Compilacion

- Linux/macOS: `./build_presentacion.sh`
- Windows PowerShell: `./build_presentacion_windows.ps1`

El PDF se genera en `generated/`, que no se versiona. Si luego se importa en
Google Slides, comparar visualmente todas las diapositivas con el PDF original.

# Salidas generadas

Los scripts de compilacion escriben aqui PDFs y otros formatos derivados. Git
ignora todo el contenido de esta carpeta excepto este README porque las salidas
deben poder reconstruirse desde las fuentes.

Antes de entregar, verificar que el PDF abre correctamente, que no hay
placeholders pendientes y que todas las fuentes, imagenes y enlaces se ven como
se espera.

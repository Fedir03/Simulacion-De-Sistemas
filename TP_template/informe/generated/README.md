# Salidas generadas

El script de compilacion escribe aqui el PDF del informe y sus archivos
auxiliares. Git ignora todo excepto este README: el entregable debe poder
reconstruirse a partir del `.tex`, las figuras y las referencias versionadas.

Antes de entregar, revisar portada, indice, referencias cruzadas, bibliografia,
calidad de las figuras y ausencia de campos `COMPLETAR`.

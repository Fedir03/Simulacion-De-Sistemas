# Fuentes Java

Crear aqui el paquete del nuevo TP, por ejemplo
`ar/edu/itba/sds/tp3/`. Separar, cuando aplique, el modelo o motor, la interfaz
de comandos, la entrada/salida y el analisis.

Practicas esperadas:

- Una responsabilidad clara por clase y nombres propios del dominio.
- Semillas configurables para toda aleatoriedad.
- Validacion temprana de parametros y mensajes de error accionables.
- Formatos de entrada y salida documentados y estables.
- Ninguna dependencia del directorio de trabajo que no este explicitada.

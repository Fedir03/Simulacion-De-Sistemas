# Pruebas Java

Agregar aqui pruebas JUnit para reglas del modelo, condiciones de borde,
parsers, reproducibilidad y comandos publicos. Usar tolerancias explicitas al
comparar numeros de punto flotante y cubrir tanto casos validos como errores
esperados.

Las pruebas unitarias no deben depender de archivos producidos por una corrida
manual ni escribir dentro del repositorio.
